# Learn Guitar photo workflow

For work on `learn-guitar/`, including a request to add a photographed guitar tab,
read [the photo-to-song skill](learn-guitar/skills/add-guitar-tab/SKILL.md).
It defines this songbook's input format, transcription limits, and import checks.
This guidance applies only to the guitar songbook; other projects are independent.

# Historical documentary framework

For requests to create or revise a historical documentary, read
[the documentary framework](historic-documentary/SKILL.md). It provides a reusable
research, Blender, archival-media, narration and editing workflow. Keep each film's
content and large assets in its own project; the framework contains reusable
guidance only. This guidance does not apply to ordinary historical questions.
