A QUICK REMINDER

Make it count.

  1. Add your number cards.

    The 0 card counts toward seven cards, but adds no points.

  2. Have ×2? Double that sum.

    Only the number cards get doubled.

  3. Add your bonus cards.

    Add any +2, +4, +6, +8, and +10 modifiers.

  4. Flipped seven? Add 15.

    Seven different number cards end the round for everyone.

Busted? That round is worth zero.
