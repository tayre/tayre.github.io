A quantitative refinement of a depth-three circuit lower bound

Tom Ayre · October 6, 2026 · Research preprint

Abstract

OpenAI's depth-three circuit construction gives a single polynomial-time language whose n-bit membership function requires 2ω(√n) total gates in unrestricted OR–AND–OR circuits. We derive the explicit lower bound 2c√(n ln n / ln ln n) for an absolute c > 0, at every sufficiently large input length, for the same language. The additional input is the published quantitative form of disjoint CNF sparsification, with clause density at most (Kb)Kb at width b. This permits the target width to grow as Θ(ln n / ln ln n). We verify the counting, moment, restriction, and gate-count estimates uniformly for this schedule. We also reproduce the source's finite restriction argument, including the backwards path count that removes dependence on the number of clauses. The refinement changes the proof parameters, not the language or its evaluation algorithm.

S3(fn)> 2cnln⁡nln⁡ln⁡n

For some absolute c > 0 and every sufficiently large n. S3 counts all gates, with unrestricted fan-in and fan-out.

Contribution and status

The language and restriction lemma come from OpenAI's source manuscript. This note supplies a growing-parameter schedule and uniform estimates, using the published sparsification bounds of Calabro, Impagliazzo, and Paturi, the disjoint refinement of Dell and coauthors, and the quantitative counting form used by Williams.

The theorem is asymptotic, and the current proof uses an extremely large threshold. The revised proof makes the finite sparsification statement, disjointness, and uniform constants explicit. It also explains the limitation imposed by the available sparsification bound.

Novelty and publication priority remain unconfirmed. This preprint has not undergone external peer review. The Python checks are finite diagnostics, not a formal verification. No fresh Lean kernel verification was performed. The manuscript was prepared with assistance from Codex.

Run the checks

Download both Python files and run them with Python 3.11 or later. They use only the standard library.

python3 check_quantitative_depth_three.py
python3 check_restriction_lemma.py

To rebuild the PDF, download the main LaTeX source and run:
