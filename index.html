Graceful trees

Computational experiments · Tom Ayre

The Graceful Tree Conjecture states that every finite tree with n vertices can be labeled with the integers 0, …, n − 1, each used once, so that the absolute differences across its edges are exactly 1, …, n − 1.

This project searches for such labelings, independently verifies them, and studies difficult cases and restrictions on the labels. The goal is to contribute reproducible evidence and testable mathematical questions, or identify a counterexample that can be independently established.

Method and limitations

NetworkX generates non-isomorphic small trees and reproducible samples of larger trees. An exact isomorphism check removes duplicates. A known construction labels caterpillars directly; OR-Tools CP-SAT searches other trees and all restricted edge experiments. A separate verifier checks that each input is a tree, that the vertex labels are a permutation of 0, …, n − 1, and that the edge differences are a permutation of 1, …, n − 1.

The system preserves inputs, seeds, solver versions, and verified labelings. Unresolved cases are retained for further search. A secondary experiment studies which edges can carry the largest difference. Infeasibility under that extra restriction does not imply that the tree is nongraceful.

CP-SAT infeasibility is recorded separately from timeouts. This implementation does not produce independently checkable infeasibility certificates, so it cannot certify a counterexample. Exhaustive verification through 35 vertices has already been reported [1]; our smaller exhaustive runs test the implementation.

Runs are scheduled daily at 06:23 UTC with a 30-minute research budget. Configuration changes trigger shorter validation runs. GitHub may delay or skip a scheduled job. The page displays the latest audited result, and marks stale data.
